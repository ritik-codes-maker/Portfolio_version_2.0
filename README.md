# Ritik Chandravanshi | Portfolio

Personal portfolio of Ritik Chandravanshi, Full Stack Developer. Built with Next.js, React and Tailwind CSS, starting from the Paperfolio template.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Editing content

- Contact details and links: `lib/profile.ts`
- Projects: `components/portfolio-section.tsx` (add a `link` to a project to show its "View project" link)
- Experience and education: `components/experience-section.tsx`
- Resume download: replace `public/Ritik_Chandravanshi_Resume.pdf`
